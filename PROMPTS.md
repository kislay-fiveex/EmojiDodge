# Prompts Used

Prompt 1
Build an Emoji Dodge game in Jetpack Compose with a home screen, gameplay screen, and game-over screen wired with type-safe navigation.

Prompt 2
Implement a frame-based game loop, random emoji spawning from the top, and collision detection that ends the run instantly.

Prompt 3
Add pause/play controls, exit confirmation, and a survival-time scoring system shown during gameplay and on game over.

Prompt 4
Persist the high score using SharedPreferences and trigger a celebratory animation when a new high score is reached.

Prompt 5
Refine the UI to feel arcade-like with gradients, bold typography, alignment tweaks, and subtle pulsing animations.

Prompt 6
Extract Home, Game, and Game Over into separate Compose files to keep the screens independent.
